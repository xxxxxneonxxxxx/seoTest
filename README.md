# DevOps Training Starter

Небольшой учебный HTTP-сервис на Node.js без сторонних зависимостей. В проекте есть два маршрута и автоматические тесты. Настроенное логирование, Docker и CI/CD намеренно отсутствуют: это темы для практики.

## Требования

- Node.js 18 или новее
- npm (устанавливается вместе с Node.js)

## Запуск

Из корневой папки проекта:

```bash
npm test
npm start
```

Открой в браузере или проверь через curl:

- http://localhost:3000/
- http://localhost:3000/health

Остановка сервиса в терминале: Ctrl+C. Порт можно задать переменной окружения `PORT`.

## Устройство проекта

- `src/app.js` — HTTP-маршруты и ответы.
- `src/index.js` — запуск сервера.
- `test/app.test.js` — автоматические проверки.
- `package.json` — команды проекта и требуемая версия Node.js.

## Практический маршрут

Выполняй этапы по очереди, сохраняя каждый результат в Git:

1. **Git:** создай отдельный репозиторий для учебного проекта и сделай первый коммит. Не добавляй `.env` и реальные секреты.
2. **Логи:** добавь структурированные JSON-записи в stdout. Для каждого HTTP-запроса записывай время, метод, путь, код ответа и длительность. Не записывай секреты или содержимое запросов.
3. **Проверки:** добавь тест, который проверяет нужное поведение, затем проверь, что `npm test` проходит.
4. **CI:** создай workflow GitHub Actions, который устанавливает Node.js, запускает тесты при push и pull request.
5. **Docker:** добавь Dockerfile, собери образ и проверь оба маршрута в контейнере.
6. **Доставка:** добавь этап публикации образа или развёртывания после успешных проверок. Сначала будем работать в тестовой среде.
7. **Наблюдение:** проверим логи, доступность health endpoint и разберём намеренно внесённый сбой.

Не переходи к следующему этапу, пока не проверишь предыдущий локально.
